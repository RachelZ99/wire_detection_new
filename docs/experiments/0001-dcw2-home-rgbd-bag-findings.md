# DCW2 家庭 RGB-D 样本实测报告

- 数据：`wire_rgbd_strip_01`
- 日期：2026-08-25
- 场景：反光灰色地面、白色/浅粉电线、两个插线板、机器人低速移动
- 结论级别：家庭可行性证据，不代表工厂验收

## 数据完整性

| 项目 | 实测结果 |
|---|---:|
| 时长 | 35.63 s |
| RGB | 357 帧，`rgb8`，640×360，约 10 fps |
| Depth | 355 帧，`16UC1`，640×360，约 10 fps |
| RGB/Depth 坐标系 | 均为 `camera_1_color_optical_frame` |
| `/odom` | 812 条，约 23–25 Hz |
| `/tf_static` | 3 条，包含机器人到相机及相机内部外参 |
| `/camera_1/depth_to_color` | 0 条；配准关系由 CameraInfo 和 TF 提供 |

全部图像和 CameraInfo 都是 640×360。配置中预期的 640×400 没有出现在本次数据中。

## 安装与地面模型

TF 中 `base_link -> camera_1_link` 为 `(x=0.33 m, z=0.15 m)` 且无俯角，但对 8 个分散时刻的深度帧进行稳健地面拟合后得到：

- 等效光心离地高度约 0.22–0.23 m；
- 向下俯角约 2.4°–3.0°；
- 地面拟合内点比例约 85%–88%。

人工测量随后确认光心约 0.22 m，并有轻微向下俯角。因此 TF 中 0.15 m 水平安装值不能作为地面真值。

## 深度证据

- 选取帧的全图无效深度比例约 10.3%–14.5%。
- 反光地面会产生散点和片状无效深度，因此 `depth == 0` 不能单独触发障碍。
- 插线板顶部区域的有效点中，约 49% 高于拟合地面 15 mm；高度 90 分位约 33 mm。
- 相邻地面有效点中，仅约 2.5% 高于拟合地面 15 mm。
- 电线部分区域存在 6–20 mm 的离地深度证据，其他部分表现为沿 RGB 细线连续分布的无效深度带。

这证明插线板适合由通用几何通路检测；电线需要 RGB 细线证据、弱高度证据和连续空洞证据联合判断。

## 时间特性

| 指标 | P50 | P95 |
|---|---:|---:|
| RGB 帧间隔 | 100.0 ms | 100.5 ms |
| Depth 帧间隔 | 99.0 ms | 102.4 ms |
| RGB bag 到达时间减消息时间戳 | 180.5 ms | 217.6 ms |
| Depth bag 到达时间减消息时间戳 | 13.6 ms | 28.1 ms |

最近时间戳配对结果：

- 30 ms 内约 60%；
- 50 ms 内约 98%；
- 60 ms 内约 99.4%。

简单放宽像素级同步窗口会把机器人运动转化为空间错位。0.3 m/s、50 ms 对应 15 mm，因此最终架构采用各自时间戳处理并在 `odom` 中异步融合。

## 视野、footprint 与停车包络

运行中的 Nav2 参数为：

```text
footprint = [[0.375, 0.33], [0.375, -0.33], [-0.375, -0.33], [-0.375, 0.33]]
```

结合 CameraInfo、实测地面模型和相机前向安装偏移：

- 最近可见地面距相机约 0.41 m；
- 最近可见地面位于 `base_footprint` 前方约 0.74 m；
- 机器人前缘为 `x=0.375 m`；
- 车体前缘到最近可见地面的未观测间隙约 0.365 m。

在 0.3 m/s、减速度 1 m/s² 下：

```text
RGB P95 到达延迟        0.218 s
两帧确认最坏等待        0.200 s
外部响应预留            0.100 s
延迟行驶距离            0.3 × 0.518 ≈ 0.155 m
制动距离                0.3² / (2 × 1) = 0.045 m
总停车包络              ≈ 0.200 m
相对未观测间隙余量      0.365 - 0.200 ≈ 0.165 m
```

该结果支持当前 0.3 m/s 配置，但余量仍需通过整机停车测试验证。若恢复到 0.8 m/s，同样假设下停车包络约 0.734 m，超过当前未观测间隙，不能使用同一检测配置。

## 已确认的局限

- 本次运动速度约在 ±0.14 m/s 内，没有覆盖 0.3 m/s 上限。
- 只有家庭环境和少量线缆/插线板，不能推断工厂召回率。
- 未测黑色线缆、强阳光、不同环氧地坪、油污、水迹和动态遮挡。
- RGB 高延迟的来源尚未拆分为驱动、MJPEG 解码、ROS 队列或 rosbag 写入。
- `/odom` 实测约 25 Hz，而非先前预期的 100 Hz。
